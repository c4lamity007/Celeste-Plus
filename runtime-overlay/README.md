# Runtime source overlay

This directory contains changed or newly added Celeste+ runtime source and authored HUD/font assets relative to the Celeste commit pinned in `../core.lock.json`. The manifest records each exact overlay SHA-256 and its required base SHA-256; `null` means the file must be absent in the base. Text uses LF line endings; PNG files retain their exact binary bytes.

This is the current integrated development source, including the media, sky, model-import and lifecycle dependencies needed to compile it. It is not byte-identical to any previously published protected runtime payload. Preparing or compiling it does not publish, license, sign, attach, or install it.

Run `python tools/prepare_runtime.py --core-checkout /path/to/Celeste` from the Celeste+ repository. The tool reads the exact locked Git commit through `git archive`, verifies all required base hashes and overlay hashes, rejects links/traversal/collisions, and writes only a fresh `build/runtime-core`. Without a local checkout it clones the known Celeste GitHub repository into that fresh output's preparation directory. Existing output is refused and never automatically deleted. After a failed preparation, move the owned output aside explicitly before retrying.

The root lock pins the reviewed Celeste core commit. Preparation fails closed if that exact commit is unavailable or any base source hash differs. Once prepared, use that tree's Gradle wrapper to compile/remap the runtime, or pass `--build` to the preparation tool. On Windows, supply the x64 media bridge with `--build --media-dll /path/to/MediaPlayerInfo.dll` and its cleanup helper with `--media-cleanup-dll /path/to/CelesteMediaCleanup.dll`. Either explicit option can replace its resource independently. The helper generates an init script under `.prepare/` that replaces only the selected root runtime resources, without editing pinned build sources or other projects. Without either option the pinned core's existing resource behavior remains. Compile the cleanup DLL from the pinned source with `tools/build_media_cleanup.py`; Windows release packaging requires both DLLs. Generated DLLs remain outside this overlay.

No creator-owned GLB models, compiled artifacts, credentials, local profiles, authentication data, or release/signing material are included in this overlay. Model importing remains source functionality; external models and native tools must be supplied separately with their required permissions.

PNG assets are restricted to the Celeste font tree and HUD glyph directory, with bounded dimensions and checked chunk integrity. Glyph SVG sources and license attribution text are included in their specific resource directories. Each file is at most 4 MiB and the complete overlay is at most 64 MiB. Unsupported binary types remain rejected.
