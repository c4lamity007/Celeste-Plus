- VMProtect Lite 3.10.4 compiled all 14 selected functions with Virtualization,
  the existing GUI settings and 20% complexity. Ultra and whole-program
  virtualization are not claimed.
- Independent bounded loaded-code review and the exact-artifact verifier confirm
  entry paths into operand decoding, rolling-key updates and dispatch for all
  14 selections. A second reviewer checked the seven newly added paths and the
  final verifier. This is transformation evidence, not full semantic equivalence.

  warnings-denied compilation and the actual local debugger probe passed.
- Raw and protected Windows builds opened successfully. Startup testing found
  and fixed the x64 thread-context alignment defect before deployment. Rejected
  candidate 03 is retained as diagnostic evidence only.
- The exact verifier, protection gate, GUI importer and MAP-profile suite passed
  81 tests. The manual publisher's six offline state-binding tests passed, with
  external services and OS protection gates explicitly mocked.
- The upgraded VMProtect MCP passed 107 tests with two permission skips. Compile
  06 recorded the exact **No** response and stable output hashes. The bridge did
  not execute the compiled output; controlled startup verification was separate.

VM/sandbox and debugger checks remain enforced. Local fixtures and this physical
Windows system do not demonstrate detection of every possible guest environment.
No protected authentication, game injection or performance result is inferred
from startup or code review. The user chose to handle the Minecraft check.
