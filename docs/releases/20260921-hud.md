# Celeste+ compact HUD release — 2026-09-21

Published release: `celeste-plus-20260921-hud-01`.

## Presentation changes

- Compact coordinates, performance, effects, keybinds and watermark widgets using the supplied SF Pro font. No new icon glyphs were created.
- Array List uses connected dark rows without an outer glow, configurable pink/lavender gradient text, and a continuous per-fragment enchant-style glint. Moving it across the screen midpoint mirrors the rows so the flat edge faces the nearest screen edge.
- Uniform HUD scaling prevents horizontally compressed text. Edge resizing works on either axis without overwriting the selected scale.
- Media HUD has Dynamic Island and Classic Card styles. The island includes synchronized lyrics, reserves artwork space during decoding, clips to its animated width, and crossfades phrases over 220 ms.

## Animation fixes

- Island animation advances once per rendered HUD frame, not when hit testing or clamping.
- Growing/shrinking near screen edges retains the intended center instead of accumulating sideways drift.
- Content resizing preserves the HUD drag interpolation gap; animated dimensions do not trigger config writes every frame.
- Old/new phrases are fitted to the target width once, avoiding changing ellipsis during the width transition.
- Every Array List row receives the full glint sweep, including long lists. Adjacent row backgrounds no longer overlap with double alpha.
- Zero elapsed animation time does not snap dimensions to the target.
