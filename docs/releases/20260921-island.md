# Celeste+ — Dynamic Island and compact HUD

Release: `celeste-plus-20260921-island-01`.

## Changes

- Dynamic Island is a separate HUD widget, pinned top-center and excluded from dragging/scaling. Existing island-style Media HUD layouts migrate; the separate Media HUD stays a movable card.
- A single lyric row uses SF Pro, timed brightening and animated phrase transitions. LRCLIB line-only lyrics still use estimated within-line timing, not guaranteed word timestamps.
- Module changes briefly replace media with matching green/red text and a one-second countdown dot. Only the latest toggle is retained. The island is also drawn over the Celeste menu.
- Artwork keeps its aspect ratio. A public HTTPS clock sits beside the capsule, using the local timezone. No commands, credentials or OS wall-time fallback; unavailable/stale time displays `--:--`. It retries with backoff and stops on disable/unload.
- HUD text color is under Settings. Coordinates use comma-separated numbers. Performance combines FPS, BPS and TPS in one row. Cooldowns and separate TPS are removed. Effects/keybind widths fit their contents; pink hover marks are removed.
- Array List keeps its gradient/glint, uses the configured glass, and has square row backgrounds.
- Hand Shaders has Smoke and Flame. Both include outline/glow; Flame rises and trails motion. Old mode values migrate to Smoke. GUI descriptions are shorter.
