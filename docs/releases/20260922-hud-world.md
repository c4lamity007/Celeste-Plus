# Celeste+ — HUD polish, block ESP and Freecam

Published release: `celeste-plus-20260922-hud-world-01`.
Verified live at `2026-09-22T00:54:39Z`.

## Changes

- Smoke restores the protected pre-Flame `celeste-plus-20260921-hud-01` effect, verified against the recovered shader rather than recreating it from memory. Flame history delay is shortened from 85 ms to 70 ms; Smoke retains 85 ms.
- Dynamic Island lyrics never display ellipses. Long phrases use a clipped, word-following viewport; original lyric word offsets are preserved. Added a pause indicator and subtle frame-time-based hover/press feedback using existing assets.
- Array List uses one adaptive, anti-aliased contour with small curved steps and a straight monitor-facing edge. Tiny row-width differences reduce the curve radius instead of overlapping translucent panels. Text gradient/glint remains unchanged.
- Armor icon and durability text are vertically centered as a group. Durability bars remain removed. Watermark text uses measured font bounds for centering.
- Media HUD sizes to its metadata within a compact 146–196 px width and adapts title/artist font sizes without horizontally squashing text. Control drawing and click targets share the same layout.
- Module toggles play short vanilla sounds. Startup/world changes are quiet and rapid changes do not queue a backlog.
- Sky Lyrics no longer disables its own rendering when F1 hides the HUD.
- Storage ESP and Block ESP add searchable block selectors with native item textures, persistent selections and selected-only filtering. Storage presets include containers and villager workstations. Only loaded terrain is scanned; scanning, cache validation and rendered boxes have bounded budgets.
- Freecam adds a detached render camera without replacing the network player. Mouse input uses vanilla post-sensitivity deltas and pitch clamping. Camera movement keys do not drive the real player; manual attack/use/mining queries originate from the real player, not the detached camera.
- Manual clicks retain the selected silent rotation while automated actions continue to yield to manual input. Exception-safe action scopes restore the visible look and crosshair afterward.
- Sword Aura adds `Movefix mode`: `Default` retains the existing correction; `Anarchy` keeps forward input aligned with silent yaw. Existing elytra rotation lifecycle checks remain passing.
