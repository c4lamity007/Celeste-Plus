## Updating

Use the new launcher; the protocol does not fall back to Bearer authentication.
For normal Celeste, download the new `Celeste.jar` and replace the old bootstrap
in the intended Fabric instance; do not keep duplicate copies. Celeste+ downloads
the current release through the updated Windows launcher. Restart an existing
game session before loading the new release. Licenses and existing saved
activations were not reset. Cloud configs and their storage were preserved.

Windows distributions are `Celeste.exe` and `Celeste+.exe`. Standard also ships
`Celeste-macos-arm64.zip`, `Celeste-macos-x64.zip`, and
`Celeste-linux-x64.tar.gz`. Mac applications are ad-hoc signed, not notarized.
Linux requires a desktop Secret Service, `secret-tool` and folder chooser portal.
